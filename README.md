# FreshCart Pipelines

Data Engineering Assignment: From Git to Gold.

## Project Overview

This project demonstrates four components of a modern data engineering platform.

## Project Structure

- elt/: FreshCart ELT pipeline using Snowflake.
- iris_project/: Machine Learning pipeline using Mage.
- stream/: RabbitMQ event streaming implementation.
- tests/: Automated testing using pytest.

## Technologies Used

- Git and GitHub
- Python
- Snowflake
- Mage
- RabbitMQ
- Scikit-learn
- Pytest
- GitHub Actions
